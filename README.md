# Marcus — Foundational Docs

Foundational advertising docs from Mark Builds Brands, packaged so a Claude agent can use them directly.

**To use with Claude:** clone or download this repo, point Claude at it, and tell it:

> Based on everything you know about me, about my business, and what I'm selling (product), use these Foundational Docs.

`CLAUDE.md` tells Claude what each doc is for and the order to run them in.

```
git clone https://github.com/A-Kabbara/Marcus.git
```

Contents: `Foundational Docs/` (the 7 docs), `SKILL.md` + `references/` (a Claude skill built from the material), `transcripts/` (104 video transcripts), `scripts/` (the pipeline that built this).
