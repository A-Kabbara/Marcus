# Marcus — Foundational Docs

Foundational advertising docs from Mark Builds Brands, packaged so a Claude agent can run the whole workflow from zero.

**To use with Claude:** clone this repo and start Claude inside the folder (Claude Code reads `CLAUDE.md` on its own), or paste this:

> Clone https://github.com/A-Kabbara/Marcus, read CLAUDE.md, and do what it says. Start with Phase 0.

Claude will ask you about your business, your product and your customer, then build the four foundational documents (research, avatar sheet, offer brief, necessary beliefs) and write ads from them.

```
git clone https://github.com/A-Kabbara/Marcus.git
```

Contents: `CLAUDE.md` (the runbook), `templates/` (intake + the four doc templates), `Foundational Docs/` (the 7 source docs), `SKILL.md` + `references/` (a Claude skill built from the material), `transcripts/` (104 video transcripts), `scripts/` (the pipeline that built this).
